# 飞牛官方应用中心上架手册

> 目标:把 PigeonBox fpk 提交进飞牛 fnOS 官方应用中心。官方文档:<https://developer.fnnas.com/docs/guide/publish/on-shelf>(「上架应用」章节)。
> 现状(2026-10-09):官方**邀请制**人工提交;自助开发者后台(developer.fnnas.com「我的应用」)已上线但上架仍走邀请,官方明言「后台上线后以后续平台流程为准」。

## 一、提交路径(需真人操作)

1. **进粉丝群**:飞牛官网 <https://fnnas.com> 右上角「关注飞牛」→「微信群」分类,扫码进任意粉丝群。
2. **对接主理人**:群内联系飞牛社区主理人,申请加入「**应用中心开发者先锋交流群**」。
3. **按工作人员指引提交**:提交本仓组装好的材料包(见下节),应用信息+fpk+测试材料,官方审核后上架。
4. 同时在 developer.fnnas.com 注册开发者账号占位,后台自助流程开放后无缝切换。

## 二、材料包组装(可代办,每列车重跑)

```bash
cd PigeonBox/fnos
./scripts/assemble-store-package.sh            # 缺省读 VERSION,从 hub Release 拉 fpk
./scripts/assemble-store-package.sh 1.14.5     # 指定版本
FPK_SRC=./fnos/pigeonbox.fpk ./scripts/assemble-store-package.sh   # 用本地构建的 fpk
```

产物 `dist/store-submission/pigeonbox-fnos-store-v<版本>.zip`(已 gitignore):

| 内容 | 说明 |
|---|---|
| `pigeonbox.fpk` | hub Release `fnos-v<版本>` 资产(含双架构二进制+内嵌前端) |
| `ICON.PNG` / `ICON_256.PNG` | 现役品牌图标;脚本会与打包源 cmp 校验代际 |
| `screenshots/` 8 张 | 全部 1366×900 真实 UI,取自 docs-site 截图流水线(发送×2/分享成功/首页取件/密码保护/文本内容/多文件下载/管理控制台) |
| `提交说明.md` | 给审核者看的应用简介/功能亮点/测试情况/更新承诺 |

截图若需更新:重跑 docs-site 截图流水线(hub 仓,2026-10-08 已对齐新 UI),再跑本脚本;`SHOTS_DIR` 可指向其他目录。

## 三、发布前测试基线(官方要求)

官方要求在「计划支持的 fnOS 版本和硬件架构」实测后才可声明支持范围。已覆盖:

- fnOS 1.2.0701 x86_64 真机:全新安装/桌面入口/启停/应用内升级/卸载重装/看门狗自愈全绿(见 fnos v1.2.7+ 真机回归记录)。
- **缺口**:aarch64 真机未实测(包内有双架构静态二进制,但仅 CI 冒烟)——提交前如实向工作人员说明,或找 ARM 设备补测。

## 四、提交前待确认项(逐项打钩)

- [ ] **os_min_version 口径**:manifest 现申报 `1.1.3100`,但实测仅 1.2.0701——官方要求「根据实际测试过的版本设置,不要声明超过应用真实支持能力的范围」。与工作人员确认申报口径(保守=1.2.0 或实测版本)。
- [ ] **maintainer/distributor 名义**:现为个人(zhangyi)。确认是否须以 PigeonBox 组织名义提交,及是否要求企业/实名认证。
- [ ] **提交版本选择**:v1.14.4(已发布+真机验证)先行占坑,还是等「深度融合」波(micro_app/统一网关免登录,开发中)落地的下一列车。建议:材料先行、版本与审核节奏听工作人员安排。
- [ ] **应用名重名**:向工作人员确认「PigeonBox/文件快递柜」在应用中心无重名/相似冲突。
- [ ] **后台账号**:developer.fnnas.com 注册开发者账号(飞牛账号体系),上架切自助后需用。

## 五、上架后持续运营

- **每列车同步**:train 发版 → CI 产出 fpk 挂 hub Release → 重跑 `assemble-store-package.sh` → 群内提交新版(与 iStore PR 同节奏)。manifest `changelog` 即版本说明,确保每列车已更新。
- **官方审核退回**:按群内反馈修;审核周期未知,首版按 1-2 周预期。
- **紧急修复**:P0 热修列车发版后,主动在群内说明修复内容加速审核(参考 iStore 渠道经验)。

## 六、审核关注点预备(内容安全类应用)

匿名分享类应用审核大概率关注内容合规,已有应对:

| 可能问询 | 事实依据(如实陈述) |
|---|---|
| 匿名滥用/违法内容 | 页脚合规声明(网络安全法);moderation 域内置敏感词审核钩子(可配 ClamAV) |
| 账号滥用 | 默认关闭开放注册(管理员建号);生产模式库中无 admin 且未注入密码拒绝启动 |
| 数据安全 | 数据全落用户自有 NAS 共享目录;支持取件密码与端到端加密分享;到期自动销毁 |
| 端口/暴露面 | 单进程单端口(默认 12345);管理面可独立门禁;不收集外部数据(全开源可审计) |
